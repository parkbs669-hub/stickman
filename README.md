# Tennis Stickman v12.4 업그레이드

테니스 영상의 선수 자세를 MediaPipe로 추출하고, 스틱맨·라켓·스윙 궤적·관절각·임팩트 효과를 영상으로 만드는 프로그램입니다. 지정한 v12.4를 기반으로 수정했습니다. 기존 폴더의 v12.4, v12.5, v13 파일은 수정하지 않았습니다.

## 추가 수정 · upgrade.2

- 라켓: 팔꿈치→손목 연장선 대신 검지·새끼손가락의 그립 축을 사용합니다. 화면 비율과 각도 경계를 반영해 부드럽게 갱신합니다. 손가락이 겹치거나 신뢰도가 낮을 때는 짧게 유지한 후 팔 방향 추정으로 대체합니다. 실제 라켓 물체를 검출하는 기능은 아니므로 모든 프레임의 정확한 각도를 보장하지는 않습니다.
- 발: 14~16초 구간의 가까운 발이 수직을 지날 때 신발 폭 방향이 순간 뒤집히던 문제를 수정했습니다. 실제 발목 위치는 유지하고 신발 모양과 각도만 안정화합니다.
- 의상: 흰색 상의와 붉은색 반바지를 적용했습니다.
- `examples/racket_correction.png`는 지적한 스크린샷에 해당하는 장면의 원본·수정 전·수정 후 비교입니다. `examples/foot_14_16_before_after.mp4`는 발의 수정 전·후 확대 비교입니다.

## 바로 실행

1. `실행하기.cmd`를 더블클릭합니다. ZIP을 받았다면 먼저 전체를 압축 해제하세요.
2. **영상 파일**을 선택하고 **결과 이름**, **저장 폴더**, 배속과 동작을 지정합니다.
3. **영상 만들기**를 누릅니다. 완료되면 **결과 폴더 열기**를 누릅니다.

현재 PC에서 확인한 Python 3.13 환경을 실행기가 자동으로 찾습니다. `forehand`는 포핸드, `backhand`는 백핸드, `serve`는 서브입니다. 왼손잡이 양손 백핸드는 두 옵션을 모두 체크합니다. 처리 중에는 창을 닫을 수 없고, 완료 후 닫을 수 있습니다.

`examples/alcaraz_upgrade_preview_stickman.mp4`는 기존 알카라스 영상으로 만든 **24초, 0.5배속 원본 비교 영상**입니다. 함께 제공하는 `preview.png`로 화면을 확인할 수 있습니다.

## 수정한 내용

| 기존 문제 | 업그레이드 동작 |
|---|---|
| 슬로모션 영상에 원래 길이의 오디오를 붙이고 `-shortest`로 잘라냄 | 음정 유지 배속 필터, 부족한 오디오 패딩, 최종 영상 길이에 맞춘 합성 |
| 이름·프레임 수만 같으면 다른 영상의 자세 캐시 사용 | 원본 전체 SHA-256, 모델, 구간, FPS, 추출 설정, 랜드마크 구조 검증 |
| 자세 스무딩에서 visibility가 사라짐 | 추출 → 스무딩 → 캐시 저장/복원까지 신뢰도 보존 |
| 수동 임팩트가 서브 자동 감지·중복 제거로 바뀜 | 수동 지정 프레임을 우선 적용하고 범위 오류를 명확히 안내 |
| 감지 실패 시 영상 중앙을 임팩트로 표시 | 검출하지 못하면 임팩트 효과 생략 |
| 왼손잡이 양손 그립 누락 | 왼손잡이도 반대 손을 그립 위에 배치 |
| SSAA를 선 두께에 두 번 곱함 | 최종 해상도 기준으로 일관된 선 두께 |
| 손목 속도 화살표가 실제 그려진 손목과 어긋남 | 같은 좌표 변환 사용 |
| 누락 프레임에서 인물이 깜빡임 | 약 0.15초 이내의 짧은 누락만 보간. 장면 전환·긴 누락은 생략 |
| 추적 실패·인코딩 실패에도 성공처럼 끝날 수 있음 | 명확한 오류와 종료 코드, 임시 파일 정리, 완료 후에만 결과 교체 |
| 세로 화면의 긴 한글 제목 잘림 | 패널 폭에 맞춰 글자 크기 조절 |
| TrackNet 320×180 입력의 풀링 크기 불일치 | 640×360 입력, 최근 3프레임만 보관, 히트맵 밝기 오버플로 수정 |

추가 옵션: 원본 비교 화면, 구간 선택, 해상도·SSAA, 출력 폴더, 무음 출력, 캐시 생략, JSON 분석 결과.

원본 v12.4의 전체 프레임 다리 방향 강제 교정·동결·최소 간격 강제는 정상적인 발 교차까지 바꿀 수 있어 기본 적용에서 제외했습니다. 이전 표현이 필요하면 `--legacy-leg-fix`를 사용하세요. 짧은 프레임 사이 좌우 레이블 교정은 유지합니다.

## 명령줄 사용

아래 `python`은 의존성이 설치된 Python 3.13을 의미합니다. 이 PC의 기본 `python`은 3.14이며 MediaPipe가 없으므로, **실행하기.cmd 사용을 권장**합니다. PowerShell에서 3.13을 직접 선택하려면 다음과 같이 실행합니다.

```powershell
$py = Join-Path $env:LOCALAPPDATA 'Programs\Python\Python313\python.exe'
& $py .\tennis_stickman_v12_4_upgraded.py 'D:\영상\포핸드.mp4' forehand --compare --ensemble --speed 0.5
```

```powershell
# 5초부터 8초 구간, 1080p, 원본 비교, 한글 제목
& $py .\tennis_stickman_v12_4_upgraded.py 'D:\영상\포핸드.mp4' analysis --start 5 --duration 8 --height 1080 --compare --label '포핸드 분석'

# 왼손잡이 양손 백핸드
& $py .\tennis_stickman_v12_4_upgraded.py 'D:\영상\백핸드.mp4' backhand --stroke backhand --left --two-handed --strobe

# 수동 임팩트: 선택 구간의 첫 프레임을 0으로 계산
& $py .\tennis_stickman_v12_4_upgraded.py 'D:\영상\서브.mp4' serve --stroke serve --impact-frame 60 120

# 모든 옵션
& $py .\tennis_stickman_v12_4_upgraded.py --help
```

기본 결과는 실행한 위치의 `renders` 폴더에 저장됩니다. GUI는 프로그램 폴더의 `renders`를 사용합니다. 같은 이름이 있으면 오류로 알려 주므로 이름을 바꾸거나 명령줄에서 `--overwrite`를 명시하세요.

- `이름_stickman.mp4`: H.264 영상 + 원본에서 가져온 배속 오디오
- `이름_analysis.json`: 프레임 수, 실제 출력 길이, 자세 누락, 캐시 사용, 임팩트 시각과 추정 방식
- `이름_pose_cache.json`: 입력과 추출 설정이 일치할 때 재사용하는 자세 데이터

배속 범위는 0.05~8입니다. 영상은 원본 FPS에서 프레임을 반복/생략하며, 새로운 중간 동작을 생성하는 AI 프레임 보간은 아닙니다. 임팩트 프레임은 선택 구간 기준이고 배속 적용 전의 번호입니다.

## 다른 PC에 설치

Python 3.13과 FFmpeg/FFprobe가 필요합니다. 프로그램 폴더에서 다음을 실행하세요.

```powershell
python -m pip install -r requirements.txt
ffmpeg -version
ffprobe -version
```

MediaPipe 모델은 `models/pose_landmarker_full.task`에 포함했습니다. 모델이 없으면 기본 모델을 내려받으며, `--model`로 다른 파일을 지정할 수 있습니다. 한글 경로에서도 모델을 읽도록 파일 바이트를 모델 API에 전달합니다.

로컬 파일 처리에는 별도 인터넷 연결이 필요하지 않습니다. URL 입력은 선택 기능이며 `python -m pip install yt-dlp`가 추가로 필요합니다. TrackNet은 `torch`와 호환 가중치가 별도로 필요합니다. 기본 자세/오디오 기능은 torch가 없어도 동작합니다.

## 검증과 한계

`VALIDATION.md`에 실제 실행 결과와 재현 명령을 기록했습니다. 자동화 테스트는 `python -m unittest discover -s tests -v`로 실행합니다.

자동 임팩트는 오디오·팔 신장·관절각을 조합한 **추정값**입니다. 모든 타구의 실제 접촉 프레임을 보장하지 않습니다. 시범 영상의 추정 프레임 217도 정답 라벨로 검증한 값은 아닙니다. 정확한 시점이 필요하면 원본을 확인해 `--impact-frame`을 지정하세요.

라켓은 손·팔 자세에서 추정해 그립니다. 기본 모드에서 실제 라켓이나 공을 직접 추적하는 것은 아닙니다. 가림, 카메라 전환, 화면 가장자리에서는 자세가 부정확하거나 일부 도형이 잘릴 수 있습니다. TrackNet의 공 추적 정확도는 전체 데이터셋으로 검증하지 않았습니다. 가변 프레임률 영상은 OpenCV가 보고하는 평균 FPS를 사용하므로 정밀 분석 전에 고정 FPS로 변환하는 편이 좋습니다.
